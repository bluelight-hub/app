## Story

**As a** FükW-Personal,
**I want** POIs (Fahrzeuge, Gefahrenquellen, Versorgungspunkte) manuell auf der Karte platzieren,
**so that** ich die Einsatzlage strukturiert erfassen und dokumentieren kann.

## Acceptance Criteria

1. POI-Toolbar zeigt POI-Typen (12 Typen: Fahrzeug, Einheit, Versorgungspunkt, etc.)
2. User klickt Typ → Cursor wechselt zu "Platzierungs-Modus"
3. Klick auf Karte → POI-Erstellungs-Modal (Headless UI):
   - Name-Input (z.B. "Versorgungspunkt West")
   - Adresse-Input (optional, für Geocoding)
   - Icon-Auswahl (Standard pro Typ vorausgewählt)
4. Modal-Speichern → POI wird in Backend erstellt
5. POI erscheint als Marker auf Karte
6. POI ist verschiebbar (Drag & Drop → `PUT`)
7. POI ist löschbar (Rechtsklick → "Löschen" → `DELETE`)

**Integration Verification:**

- IV1: POI-CRUD funktioniert (Create, Read, Update, Delete)
- IV2: POI-Änderungen persistieren (Page-Reload → POIs bleiben)
- IV3: Multi-Device: POI auf Device A → erscheint auf Device B nach Reload

### Component Architecture

[Source: docs/development/coding-standards.md#Frontend (React + TypeScript)]

**Form Pattern (TanStack Form + Zod):**
```tsx
// ✅ CORRECT: TanStack Form with Zod validation
import { useForm } from '@tanstack/react-form';
import { z } from 'zod';

const schema = z.object({
  name: z.string().min(3),
  adresse: z.string().optional(),
  latitude: z.number(),
  longitude: z.number(),
});

export const usePoiForm = () => {
  const form = useForm({
    defaultValues: { name: '', adresse: '', latitude: 0, longitude: 0 },
    onSubmit: async ({ value }) => {
      const validated = schema.parse(value);
      await createPoiMutation.mutate(validated);
    },
  });
};

// ❌ WRONG: HTML forms or Redux
```

**Mutation Pattern (TanStack Query):**
```typescript
// ✅ CORRECT: TanStack Query Mutation with cache invalidation
import { useMutation, useQueryClient } from '@tanstack/react-query';

export const useCreatePoi = (einsatzId: string) => {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: (data: CreatePoiDto) => api.lagekarte().createPoi(data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['pois', einsatzId] });
    },
  });
};
```

### Geocoding Integration

[Source: docs/bmad/prd/lagekarte-prd.md#2.1 Functional Requirements]

**Geocoding Workflow:**
1. User types address in "Adresse" field
2. Debounce 1 second (use TanStack Pacer or `setTimeout`)
3. Call `POST /einsatz/{einsatzId}/geocode` with `{ address: string }`
4. Update form fields: `latitude` and `longitude` with result
5. If geocoding fails: Show warning toast, allow manual coordinate input

**Implementation:**
```typescript
import { useDebounce } from '@tanstack/pacer'; // or custom debounce

const debouncedGeocode = useDebounce(async (address: string) => {
  const result = await api.lagekarte().geocode(einsatzId, { address });
  if (result) {
    form.setFieldValue('latitude', result.lat);
    form.setFieldValue('longitude', result.lon);
  } else {
    showToast('Geocoding fehlgeschlagen', 'warning');
  }
}, 1000);
```

### Security Considerations

[Source: docs/development/coding-standards.md#Security Standards]
