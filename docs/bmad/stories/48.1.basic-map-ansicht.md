## Story

**As a** FükW-Personal (Führungskraft vom Wachdienst),
**I want** eine interaktive Karte im Einsatz-Detail sehen,
**so that** ich den Einsatzort geografisch verorten und die Lagekarte pflegen kann.

---

Diese Story ist die **erste Story in Epic 48** und hat keine Abhängigkeiten zu anderen Stories.

- ✅ Bestehende Einsatz-Detail-Route (`/app/einsaetze/$einsatzId`) ist implementiert

## Acceptance Criteria

1. Lagekarte-Tab erscheint in Einsatz-Detailansicht (neben "Details", "ETB")
2. Karte zeigt OpenStreetMap-Tiles an (Zoom, Pan funktioniert)
3. Initiale Map-Position: Deutschland-Zentrum (fallback)
4. Mobile-responsive (Touch-Zoom, Swipe-Pan)
5. Loading-Spinner während Tile-Loading
6. Dark-Mode: Map-Tiles wechseln zu CartoDB Dark Matter

**Integration Verification:**

- IV1: Bestehende Einsatz-Detail-Navigation funktioniert
- IV2: Keine Performance-Degradation in anderen App-Bereichen
- IV3: Tailwind-CSS-Konsistenz

### Map Configuration

- Zoom: `6` (country-wide view)

### Leaflet Integration Notes

[Source: docs/bmad/features/lagekarte/epic-48-lagekarte.md#Dependencies & External Libraries]

**Leaflet Setup:**
```tsx
import { MapContainer, TileLayer } from 'react-leaflet';

<MapContainer
  center={[51.1657, 10.4515]}
  zoom={6}
  className="h-full w-full"
>
  <TileLayer
    url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png"
    attribution='&copy; <a href="https://osm.org/copyright">OpenStreetMap</a> contributors'
  />
</MapContainer>
```

**Important:** Leaflet CSS must be imported globally:
```tsx
// MUST import in packages/frontend/src/main.tsx for global availability
import 'leaflet/dist/leaflet.css';
```

**Rationale:** Leaflet CSS should be global, not component-scoped, to ensure consistent styling across all map-related components.

[Source: docs/development/coding-standards.md#Security Standards]

**Authentication & Authorization:**
- Route `/app/einsaetze/$einsatzId/lagekarte` requires authenticated user
- Apply `@UseGuards(JwtAuthGuard)` at route level (handled by parent route)
- No additional authorization needed for this story (read-only map view)

**External Resources Security:**
- **Tile URL Validation:** Validate tile URLs to prevent injection attacks

- No sensitive data in this story (read-only map view)
