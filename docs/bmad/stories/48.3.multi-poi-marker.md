## Story

**As a** Einsatzleiter or FükW-Personal,
**I want** alle POIs (Einsatzort, Fahrzeuge, Gefahrenquellen) als Marker sehen,
**so that** ich die gesamte Einsatzlage erfassen kann.

---

## Prerequisites

Diese Story setzt die erfolgreiche Implementierung folgender Stories voraus:

- ✅ **Story 48.1 (Basic Map-Ansicht)** - Bereitstellung der `LagekarteView` Komponente und Leaflet-Integration
- ✅ **Story 48.2 (POI-Management-System)** - Bereitstellung der POI-API (`GET /einsatz/:einsatzId/lagekarte/pois`) und generierter API-Client

**Wichtig:** Beide Stories müssen vollständig implementiert sein, bevor diese Story begonnen wird.

---

## Acceptance Criteria

1. Alle POIs werden als Marker angezeigt (Icons basierend auf `PoiType`)
2. EINSATZORT-POI: Primäres Icon (rot, größer)
3. Andere POIs: Typ-spezifische Icons (Open-Source SVG)
4. Marker-Popup zeigt: POI-Name, Typ, Adresse
5. Map zoomt auf Bounding-Box aller POIs
6. Kein Marker bei fehlenden POIs (Fallback: Deutschland-Zentrum)

**Integration Verification:**

- IV1: POI-Update → Marker aktualisiert sich (TanStack Query)
- IV2: Mehrere POIs → alle Marker sichtbar, Clustering bei >3 in Nähe
- IV3: Performance: <2s Ladezeit bei 20 POIs

// ✅ CORRECT: Functional component with TypeScript
interface PoiLayerProps {
  einsatzId: string;
}

export const PoiLayer: React.FC<PoiLayerProps> = ({ einsatzId }) => {
  const { data: pois, isLoading } = usePois(einsatzId);

          </Popup>

      ))}
    </>
  );
};

### Leaflet Marker Integration

[Source: docs/bmad/features/lagekarte/epic-48-lagekarte.md#Dependencies & External Libraries]

**Leaflet Marker Setup with react-icons:**
```tsx
import { Marker, Popup, useMap } from 'react-leaflet';
import L from 'leaflet';
import { renderToStaticMarkup } from 'react-dom/server';
import { PiMapPinFill } from 'react-icons/pi';

// Custom DivIcon with React Icon
const iconHtml = renderToStaticMarkup(
  <PiMapPinFill size={32} color="#EF4444" />
);
const poiIcon = L.divIcon({
  html: iconHtml,
  iconSize: [32, 32],
  iconAnchor: [16, 32], // Bottom center of icon
  popupAnchor: [0, -32], // Above icon
  className: 'poi-marker', // Custom CSS class
});

<Marker position={[lat, lon]} icon={poiIcon}>
  <Popup>
    <PoiPopup poi={poi} />
  </Popup>
</Marker>
```

**fitBounds for Bounding Box:**
```typescript
import { useMap } from 'react-leaflet';

const map = useMap();

map.fitBounds(bounds, { padding: [50, 50] });
```

### Map Bounds Strategy

[Source: docs/bmad/prd/lagekarte-prd.md#2.1 Functional Requirements]

**Bounding Box Behavior:**
- **If POIs exist:** Zoom to fit all POIs (with 50px padding)
- **If no POIs:** Fallback to Germany center (`[51.1657, 10.4515]`, zoom level 6)
- **Update on POI changes:** Re-calculate bounds when POIs are added/removed (TanStack Query refetch)

### Performance Considerations

[Source: docs/bmad/prd/lagekarte-prd.md#2.2 Non-Functional Requirements]

**NFR1: Performance Target:**
- Map loads in <2 seconds with 20 POIs (on 4G connection)
- **Mitigation:**
  - Use `React.memo()` for `PoiLayer` component
  - Use `useMemo()` for icon calculations
  - Lazy-load POI icons (preload in `useEffect`)

**NFR3: Mobile-First:**
- Touch-optimized marker popups (larger tap targets)
- Tailwind responsive classes for popup sizing: `w-64 sm:w-80`
