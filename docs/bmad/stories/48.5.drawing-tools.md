## Acceptance Criteria

1. Drawing-Toolbar zeigt Zeichnen-Optionen:
   - Polygon: Gefahrenbereich (rot), Sperrbereich (orange)
   - Linie: Rettungsweg (grün), Absperrung (gelb)
   - Rechteck: Schnelle Bereichs-Markierung
2. User wählt Tool → zeichnet auf Karte → Shape erscheint
3. Shapes sind editierbar (Eckpunkte verschieben, löschen)
4. Shapes haben Labels (optional: Text-Input wie "Überschwemmtes Gebiet")
5. Drawing-Layer kann ein-/ausgeblendet werden (Layer-Toggle)

**Unterscheidung POI vs. Drawing:**

- POI (Punkt): GEFAHRENQUELLE (z.B. "Gasleck an Adresse X")
- Drawing (Fläche): Gefahrenbereich-Polygon (z.B. "500m Evakuierungszone")

**Edge Case Handling:**

- Max 100 shapes per Lagekarte (Performance-Limit)
- Drawing außerhalb Map-Bounds: Clip to visible area
- Shape-Deletion: Bestätigungs-Dialog vor Löschen
- Concurrent Editing: Last-Write-Wins (dokumentiert in Story 48.8)

**Integration Verification:**

- IV1: Zeichnungen werden in `Lagekarte.state` (GeoJSON) gespeichert
- IV2: Mobile: Touch-Drawing funktioniert
- IV3: Performance: >20 Shapes + >50 POIs ohne Lag

### Component Architecture

[Source: docs/development/coding-standards.md#Frontend (React + TypeScript)]

**Drawing-Layer Pattern:**
```tsx
// ✅ CORRECT: Leaflet.PM integration with React (NOT leaflet-draw!)
import { useMap } from 'react-leaflet';
import { useEffect, useState } from 'react';
import '@geoman-io/leaflet-geoman-free';

export const DrawingLayer: React.FC<{ einsatzId: string }> = ({ einsatzId }) => {
  const map = useMap();
  const [shapes, setShapes] = useState<GeoJSON.FeatureCollection>({ type: 'FeatureCollection', features: [] });

  useEffect(() => {
    // Initialize Leaflet.PM
    map.pm.addControls({
      position: 'topright',
      drawPolygon: true,
      drawPolyline: true,
      drawRectangle: true,
      drawCircle: false,
      drawMarker: false,
      drawCircleMarker: false,
    });

    // Event handlers
    map.on('pm:create', (e) => {
      const geoJson = e.layer.toGeoJSON();
      setShapes(prev => ({ ...prev, features: [...prev.features, geoJson] }));
    });

    return () => {
      map.pm.removeControls();
    };
  }, [map]);

  return null; // Leaflet.PM renders directly to map
};
```


### Debouncing Strategy

[Source: docs/development/tech-stack.md#Frontend Stack]

**Debouncing with TanStack Pacer:**
```typescript
import { useDebounce } from '@tanstack/pacer';

const debouncedSave = useDebounce((state: GeoJSON.FeatureCollection) => {
  saveLagekarteStateMutation.mutate(state);
}, 2000); // 2 seconds delay
```

**Alternative (custom debounce):**
```typescript
import { useEffect, useRef } from 'react';

const useDebouncedSave = (state, delay) => {
  const timeoutRef = useRef<NodeJS.Timeout>();

  useEffect(() => {
    clearTimeout(timeoutRef.current);
    timeoutRef.current = setTimeout(() => {
      saveLagekarteStateMutation.mutate(state);
    }, delay);
  }, [state, delay]);
};
```

### Performance Considerations

[Source: docs/bmad/prd/lagekarte-prd.md#2.2 Non-Functional Requirements]

**NFR1: Performance Target:**
- Map loads in <2 seconds with 20 shapes + 50 POIs (on 4G)
- **Mitigation:**
  - Use `React.memo()` for `DrawingLayer` component
  - Use `useMemo()` for shape rendering
  - Leaflet optimization: `preferCanvas: true` (better for many shapes)

**Canvas vs. SVG Rendering:**
- **SVG:** Default, better for small number of shapes (<50)
- **Canvas:** Better performance for many shapes (>50)
- Set in `MapContainer`: `<MapContainer preferCanvas={true} />`

### Security Considerations

[Source: docs/development/coding-standards.md#Security Standards]

**Input Sanitization:**
- **Label text:** HTML escape all user-provided labels to prevent XSS
  - Use browser-native `textContent` instead of `innerHTML` for rendering
  - Validate max length: 255 characters
  - Strip HTML tags before saving: `label.replace(/<[^>]*>/g, '')`

**GeoJSON Validation:**
- Validate GeoJSON structure before backend save:
  ```typescript
  const isValidGeoJSON = (data: unknown): data is GeoJSON.FeatureCollection => {
    return (
      typeof data === 'object' &&
      data !== null &&
      'type' in data &&
      data.type === 'FeatureCollection' &&
      'features' in data &&
      Array.isArray(data.features)
    );
  };
  ```

**Payload Size Limits:**
- Max 2MB payload size for state JSON (prevent DoS)
- Check before sending: `JSON.stringify(state).length < 2_097_152`
- Show warning toast if limit exceeded

**Authorization:**
- Backend authorization inherited from Story 48.2 Lagekarte-API
- Only authenticated users with Einsatz-access can create/edit/delete shapes
- No additional frontend authorization logic required (backend enforces)
