3. Klick auf Cluster → Zoom in + Cluster aufteilen

5. Cluster-Icon: Tailwind-Farben (konsistent mit App-Design)

### Component Architecture

[Source: docs/development/coding-standards.md#Frontend (React + TypeScript)]

**Clustered POI-Layer Pattern:**
```tsx
// ✅ CORRECT: MarkerClusterGroup wraps Markers
import MarkerClusterGroup from 'react-leaflet-cluster';
import { Marker, Popup } from 'react-leaflet';
import { usePois } from '@/hooks/poi/usePois'; // From Story 48.2
import { getPoiIcon } from '@/utils/poi-icons'; // From Story 48.3
import { createClusterIcon } from '@/utils/cluster-icons'; // NEW in this story

export const ClusteredPoiLayer: React.FC<{ einsatzId: string }> = ({ einsatzId }) => {
  const { data: pois } = usePois(einsatzId);

  return (
    <MarkerClusterGroup
      maxClusterRadius={50}
      spiderfyOnMaxZoom={true}
      showCoverageOnHover={false}
      zoomToBoundsOnClick={true}
      disableClusteringAtZoom={18}
      iconCreateFunction={createClusterIcon}
    >
      {pois?.map(poi => (
        <Marker key={poi.id} position={[poi.latitude, poi.longitude]} icon={getPoiIcon(poi.type)}>
          <Popup>
            <PoiPopup poi={poi} />
          </Popup>
        </Marker>
      ))}
    </MarkerClusterGroup>
  );
};
```

### Custom Cluster-Icon Generation

[Source: docs/development/coding-standards.md#UI/UX Standards]

**Tailwind-Styled Cluster Icon:**
```typescript
// utils/cluster-icons.ts
import L from 'leaflet';

/**
 * Erstellt ein Tailwind-gestyltes Cluster-Icon für Leaflet MarkerClusterGroup.
 *
 * @param cluster - Leaflet MarkerCluster Objekt
 * @returns Leaflet DivIcon mit Tailwind-Styling
 *
 * Security Note:
 * - childCount kommt von cluster.getChildCount() (Leaflet API, returns number)
 * - KEIN User-Input! Numerischer Wert ist XSS-sicher in Template Literals
 * - Bei Erweiterungen: NIEMALS User-Input ohne Sanitization in HTML einfügen
 */
export const createClusterIcon = (cluster: L.MarkerCluster): L.DivIcon => {
  const childCount = cluster.getChildCount(); // Safe: Leaflet API returns number, not user input

  // Size based on count
  let size = 'w-10 h-10 text-sm'; // Small (<10)
  if (childCount >= 100) size = 'w-14 h-14 text-lg'; // Large
  else if (childCount >= 10) size = 'w-12 h-12 text-base'; // Medium

  // Generate HTML (safe: childCount is numeric, not user-controlled)
  const html = `
    <div class="${size} bg-blue-600 dark:bg-blue-800 text-white rounded-full border-2 border-blue-400 dark:border-blue-600 flex items-center justify-center font-semibold shadow-lg">
      <span>${childCount}</span>
    </div>
  `;

  return L.divIcon({
    html,
    className: 'custom-cluster-icon', // Empty class to override default styles
    iconSize: L.point(40, 40), // Base size (adjusted by Tailwind classes)
  });
};
```

### Clustering Configuration

[Source: docs/bmad/features/lagekarte/epic-48-lagekarte.md#Dependencies & External Libraries]

**MarkerClusterGroup Options:**
- **maxClusterRadius:** 50 (pixels) - Maximum distance for clustering markers
- **spiderfyOnMaxZoom:** true - Spread overlapping markers at max zoom
- **showCoverageOnHover:** false - Don't show cluster coverage polygon on hover
- **zoomToBoundsOnClick:** true - Zoom to cluster bounds on click
- **disableClusteringAtZoom:** 18 - Don't cluster at max zoom level
- **iconCreateFunction:** Custom function to generate Tailwind-styled icons

**Clustering Behavior:**
- Default zoom (6): 1000 POIs → ~10-20 top-level clusters
- Zoom in → clusters break into sub-clusters
- Max zoom (18) → individual markers (no clustering)

### Performance Considerations

[Source: docs/bmad/prd/lagekarte-prd.md#2.2 Non-Functional Requirements]

**NFR1: Performance Target:**
- 1000 POIs → <3s load time (on 4G)
- **Mitigation:**
  - Marker clustering reduces DOM nodes (1000 markers → 10-20 clusters)
  - Canvas rendering: `preferCanvas: true` (from Story 48.5)
  - TanStack Query caching

**Clustering Performance Benefits:**
- **Without clustering:** 1000 markers = 1000 DOM nodes (slow!)
- **With clustering:** 1000 markers = ~20 visible clusters (fast!)
- **Render time:** <100ms for cluster updates (zoom/pan)
