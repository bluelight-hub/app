## Story

**I want** Karten-Regionen für Offline-Nutzung herunterladen,
**so that** ich bei Funklöchern oder Zivilschutz-Szenarien die Lagekarte weiterhin pflegen kann.

### Tile Download Logic

[Source: docs/bmad/features/lagekarte/epic-48-lagekarte.md#Dependencies & External Libraries]

**Tile Download Workflow:**
1. User selects region (bounding box) and zoom levels (8-18)
2. Calculate tile URLs based on bounds and zoom:
   - Formula: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`
   - Iterate through zoom levels, calculate tile coordinates
3. Download tiles via `fetch()` and store in IndexedDB
4. Track progress: `(downloadedCount / totalCount) * 100`
5. Store with metadata: `{ url, blob, timestamp: Date.now() }`

**Example Tile Calculation:**
```typescript
// Calculate tiles for bounds and zoom level
function getTileUrls(bounds: L.LatLngBounds, zoom: number): string[] {
  const urls: string[] = [];
  const tileSize = 256; // Standard OSM tile size

  const minTile = latLngToTile(bounds.getSouthWest(), zoom);
  const maxTile = latLngToTile(bounds.getNorthEast(), zoom);

  for (let x = minTile.x; x <= maxTile.x; x++) {
    for (let y = minTile.y; y <= maxTile.y; y++) {
      urls.push(`https://tile.openstreetmap.org/${zoom}/${x}/${y}.png`);
    }
  }

  return urls;
}
```

### Storage Quota Check

[Source: docs/bmad/prd/lagekarte-prd.md#2.2 Non-Functional Requirements]

**Storage Manager API:**
```typescript
// utils/storage-quota.ts
export async function getStorageQuota(): Promise<{ used: number, available: number, percentage: number }> {
  if (!navigator.storage?.estimate) {
    throw new Error('Storage API not supported');
  }

  const estimate = await navigator.storage.estimate();
  const used = estimate.usage || 0;
  const total = estimate.quota || 0;
  const available = total - used;
  const percentage = (used / total) * 100;

  return {
    used: Math.round(used / (1024 * 1024)), // MB
    available: Math.round(available / (1024 * 1024)), // MB
    percentage: Math.round(percentage),
  };
}
```

### TTL Cleanup Strategy

[Source: docs/bmad/features/lagekarte/epic-48-lagekarte.md#Dependencies & External Libraries]

**30-Day TTL:**
- Store tile download timestamp: `timestamp: Date.now()`
- On app startup: Check tile timestamps
- Delete tiles older than 30 days: `Date.now() - timestamp > 30 * 24 * 60 * 60 * 1000`

**Cleanup Implementation:**
```typescript
// utils/offline-cleanup.ts
export async function cleanupExpiredTiles(): Promise<void> {
  const db = await openIndexedDB('lagekarte-offline');
  const store = db.transaction('tiles', 'readwrite').objectStore('tiles');
  const allTiles = await store.getAll();

  const now = Date.now();
  const ttl = 30 * 24 * 60 * 60 * 1000; // 30 days

  for (const tile of allTiles) {
    if (now - tile.timestamp > ttl) {
      await store.delete(tile.url);
    }
  }
}
```

const [isOnline, setIsOnline] = useState(navigator.onLine);

  const handleOnline = () => setIsOnline(true);
  const handleOffline = () => setIsOnline(false);

  window.addEventListener('online', handleOnline);
