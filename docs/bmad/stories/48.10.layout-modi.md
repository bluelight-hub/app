## Acceptance Criteria

### Functional Requirements

1. **Standard-Modus (Default):**
   - Ohne Query-Parameter oder mit `?mode=standard` wird die normale Integration in SingleEinsatzLayout verwendet
   - Alle Standard-UI-Elemente (Header, Sidebar, Navigation) sind sichtbar

2. **Fullscreen-Modus:**
   - Query-Parameter `?mode=fullscreen` aktiviert Fullscreen-Layout
   - Header und Sidebar werden ausgeblendet
   - Schließen-Button (oder Zurück-Button) ist oben rechts sichtbar
   - Minimale UI-Elemente bleiben für Navigation erhalten

3. **Präsentations-Modus:**
   - Query-Parameter `?mode=presentation` aktiviert Präsentations-Layout
   - Reduzierte UI für Präsentationen/Dashboards
   - Keine Navigation, maximale Kartenansicht
   - Optimiert für Vollbild-Präsentation auf großen Displays

4. **Karten-Funktionalität:**
   - In allen Modi ist die Karte vollständig funktional (Zoom, Pan)
   - Alle POI-Features funktionieren in allen Modi

5. **Transitions:**
   - Wechsel zwischen Modi sind nahtlos
   - Keine Fehler beim Navigieren zwischen verschiedenen Modes

6. **Responsive Design:**
   - Alle Modi funktionieren auf verschiedenen Viewport-Größen
   - Mobile-optimierte Darstellung bleibt in allen Modi erhalten

### Integration Verification

- **IV1:** LagekarteView Component akzeptiert `mode` Prop und passt Darstellung an
- **IV2:** Bestehende Lagekarte-Funktionalität bleibt in Standard-Modus unverändert
- **IV3:** TanStack Router validateSearch funktioniert korrekt für mode-Parameter

### Component Architecture

**Layout-Modi Pattern:**
```typescript
interface LagekarteViewProps {
  einsatzId: string;
  mode?: 'standard' | 'fullscreen' | 'presentation';
}

export const LagekarteView: React.FC<LagekarteViewProps> = ({
  einsatzId,
  mode = 'standard'
}) => {
  const containerClasses = cn(
    'relative w-full',
    {
      'h-screen': mode === 'fullscreen' || mode === 'presentation',
      'h-[600px] md:h-[calc(100vh-120px)]': mode === 'standard',
    }
  );

  return (
    <div className={containerClasses}>
      {mode === 'fullscreen' && <FullscreenCloseButton />}
      <MapContainer {...mapProps}>
        {/* Existing map content */}
      </MapContainer>
    </div>
  );
};
```

**Route Search Params:**
```typescript
// packages/frontend/src/routes/app/einsatz/$einsatzId/übersicht/karte.tsx
import { createFileRoute } from '@tanstack/react-router';

type LagekarteSearchParams = {
  mode?: 'standard' | 'fullscreen' | 'presentation';
};

export const Route = createFileRoute('/app/einsatz/$einsatzId/übersicht/karte')({
  validateSearch: (search: Record<string, unknown>): LagekarteSearchParams => ({
    mode: ['standard', 'fullscreen', 'presentation'].includes(search.mode as string)
      ? (search.mode as LagekarteSearchParams['mode'])
      : 'standard',
  }),
  component: LagekarteRoute,
});

function LagekarteRoute() {
  const { einsatzId } = Route.useParams();
  const { mode } = Route.useSearch();

  return <LagekarteView einsatzId={einsatzId} mode={mode} />;
}
```

### Fullscreen Close Button

**Component Implementation:**
```typescript
// packages/frontend/src/components/organisms/lagekarte/FullscreenCloseButton/FullscreenCloseButton.tsx
import { useNavigate } from '@tanstack/react-router';
import { XMarkIcon } from '@heroicons/react/24/outline';
import { cn } from '@/utils/cn';

export const FullscreenCloseButton: React.FC = () => {
  const navigate = useNavigate();

  const handleClose = () => {
    navigate({
      search: { mode: 'standard' },
      replace: true
    });
  };

  return (
    <button
      onClick={handleClose}
      className={cn(
        'fixed top-4 right-4 z-[1000]',
        'bg-white dark:bg-gray-800',
        'p-2 rounded-full shadow-lg',
        'hover:bg-gray-100 dark:hover:bg-gray-700',
        'transition-colors'
      )}
      aria-label="Vollbildmodus schließen"
    >
      <XMarkIcon className="h-6 w-6 text-gray-700 dark:text-gray-200" />
    </button>
  );
};
```

### Performance Considerations

**Performance Targets:**
- Keine Performance-Degradation durch bedingte Layouts
- Smooth Transitions zwischen Modi (CSS transitions)
- Keine zusätzlichen Bundle-Size durch einfache Layout-Logik

**Optimization:**
- Verwende CSS-only Transitions (keine JS-Animationen)
- Lazy-Loading für FullscreenCloseButton (React.lazy) falls Komponente groß wird
- Keine zusätzlichen Dependencies notwendig

### Security Considerations

**Route Parameter Validation:**
- validateSearch filtert ungültige mode-Werte
- TypeScript-Typisierung verhindert ungültige States
- Keine Security-Risiken durch Layout-Modi (rein visuelle Änderungen)

**Existing Security:**
- Authentifizierung bleibt unverändert (JwtAuthGuard auf Parent-Route)
- Keine zusätzlichen Permissions notwendig
