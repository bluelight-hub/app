## Key Learnings

### 1. `import type` bricht NestJS DI (CRITICAL)
```typescript
// FALSCH: import type wird zur Compile-Zeit entfernt
import type { MyService } from './my.service';

// RICHTIG: Regulärer Import für DI
import { MyService } from './my.service';
// Bei Biome-Conflicts: biome-ignore lint verwenden
```

### 2. NULL→undefined Mapping im Mapper (CRITICAL)
```typescript
// RICHTIG: Explizites Mapping
return {
  customLabel: entity.customLabel ?? undefined,
  beschreibung: entity.beschreibung ?? undefined,
};
```

### 3. `existsMany()` statt Loop für Batch-Validierung (PERFORMANCE)
```typescript
// FALSCH: N+1 Query Problem
for (const id of qualifikationIds) {
  await repository.exists(id);
}

// RICHTIG: Batch-Validierung
await repository.existsMany(qualifikationIds);
```

### 4. Defense-in-Depth Validierung (PATTERN)
Validierung auf allen Layern:
- Domain: Business Rules im Aggregate
- Application: Command Validation
- Controller: DTO Validation mit class-validator

### 5. REPLACE Semantik für M:N Relations (PATTERN)
Bei Update von M:N Relations: Alle bestehenden Verknüpfungen löschen, dann neu anlegen (REPLACE), nicht MERGE.
