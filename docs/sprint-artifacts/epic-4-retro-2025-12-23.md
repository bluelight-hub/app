## Key Learnings

### 1. Two Factories Pattern (NEU - KRITISCH!)

```typescript
// Factory 1: Person aus Stammdaten (KOPIERT Daten!)
public static createFromStammPerson(params: {
  einsatzId: EinsatzId;
  stammId: StammPersonId;
  vorname: string;          // KOPIE!
  nachname: string;         // KOPIE!
  funkrufname?: string;     // KOPIE!
  qualifikationIds: QualifikationId[]; // KOPIE!
}): Result<EinsatzPerson> { ... }

// Factory 2: Temporäre Person (ohne StammPerson-Referenz)
public static createTemporary(params: {
  einsatzId: EinsatzId;
  vorname: string;
  nachname: string;
  funktion: string;
}): Result<EinsatzPerson> {
  // stammId: undefined
  ...
}
```

**Warum:** Unterscheidet explizit zwischen Stammdaten-basierten und temporären Erfassungen.

### 2. Event Outbox Return Type Pattern (KRITISCH!)

```typescript
// ✅ RICHTIG: Kein Result-Wrapper in executeInTransaction
protected async executeInTransaction(
  command: Command,
  tx: TransactionContext,
): Promise<{ result: string; events: DomainEvent[] }> {
  // Base class speichert Events atomar in Outbox
  return { result: id, events };
}

// ❌ FALSCH: Result<{result, events}> bricht Outbox!
// return Result.ok({ result: id, events }); // Events werden NICHT gespeichert!
```

**Warum:** `TransactionalCommandHandler` erwartet raw `{result, events}` Object, NICHT Result-Wrapper.

### 3. Camera Lifecycle Management (Frontend)

```typescript
// ✅ RICHTIG: useEffect Cleanup + isActive Prop
useEffect(() => {
  if (!isActive) {
    // Cleanup bei Dialog Close, Tab-Wechsel, Unmount
    if (videoRef.current && videoRef.current.srcObject) {
      const stream = videoRef.current.srcObject as MediaStream;
      stream.getTracks().forEach(track => track.stop());
    }
    if (animationFrameRef.current) {
      cancelAnimationFrame(animationFrameRef.current);
    }
    return;
  }
  // Scanner starten...
}, [isActive]);
```

**Warum:** Memory Leaks verhindern bei Dialog Close, Tab-Wechsel, Component Unmount.

### 4. Per-Entity Loading State Pattern

```typescript
// ✅ RICHTIG: Per-Person Loading State
const [assigningPersonId, setAssigningPersonId] = useState<string | null>(null);

const handleAssign = (personId: string, fahrzeugId: string) => {
  if (assigningPersonId === personId) return; // Duplikat-Prevention
  setAssigningPersonId(personId);
  // ... API Call
};

// Disabled State pro Person
<Button disabled={assigningPersonId === person.id}>

// ❌ FALSCH: Global Loading State (blockiert ALLE Buttons)
const [isPending, setIsPending] = useState(false);
<Button disabled={isPending}> // Blockiert parallele Operationen!
```

**Warum:** Verhindert Race Conditions + ermöglicht parallele Operationen.
