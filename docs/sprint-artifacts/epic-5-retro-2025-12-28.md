## Key Learnings

### 1. Optimistic Locking mit updatedAt (KRITISCH!)

```typescript
// ✅ RICHTIG: updatedAt für Optimistic Locking
await client.entity.updateMany({
  where: {
    id: entity.id,
    updatedAt: existingEntity.updatedAt,  // Nur wenn unverändert
  },
  data: { ... },
});

// ❌ FALSCH: Kein Locking - Race Conditions möglich
await client.entity.update({
  where: { id: entity.id },
  data: { ... },
});
```

**Warum:** `updateMany` mit `updatedAt` Check gibt 0 affected rows bei Concurrent Modification zurück.

### 2. Query Handler für GET Endpoints

```typescript
// ✅ RICHTIG: Query Handler im Controller (Hexagonal)
@Get()
async findAll(@Param('einsatzId') einsatzId: string): Promise<...> {
  const query = FindAllQuery.create({ einsatzId });
  return this.findAllQueryHandler.execute(query.value);
}

// ❌ FALSCH: Repository direkt im Controller
@Get()
async findAll(): Promise<...> {
  return this.repository.findAll();  // Bypasses Application Layer!
}
```

**Warum:** Controller sollte nur mit Application Layer kommunizieren, nie direkt mit Infrastructure.

### 3. Soft-Delete Pattern für Audit-Trail

```typescript
// ✅ RICHTIG: Soft-Delete mit Timestamp
model EinsatzRollenbesetzung {
  freigegebenAm  DateTime?  // NULL = aktiv, DATE = freigegeben
  freigegebenVon String?    // Audit: Wer hat freigegeben?
}

// Repository Filter
where: { freigegebenAm: null }  // Nur aktive Besetzungen
```

**Warum:** Historische Daten bleiben erhalten für Reporting und Nachvollziehbarkeit.

### 4. Event Name via Static Method

```typescript
// ✅ RICHTIG: Static Method für Event-Namen
@OnEvent(RolleFreigegeben.eventName())  // 'rollen_besetzung.freigegeben'
async handle(event: RolleFreigegeben): Promise<void> { ... }

// ❌ FALSCH: Hardcoded String
@OnEvent('rollen_besetzung.freigegeben')  // Typo-anfällig!
```

**Warum:** Compile-Time Check statt Runtime-Fehler bei Typos.

### 5. Fire-and-Forget ETB mit Logging

```typescript
// ETB Handler - NIEMALS Exceptions propagieren!
try {
  await this.addEintragHandler.execute(command);
} catch (error) {
  this.logger.error(`ETB failed: ${error.message}`);
  // NICHT re-throw! Business Operation war erfolgreich.
}
```
